# Linux Homelab

Учебный проект: строю серверную лабораторию с нуля, пока учусь на сисадмина.

## Окружение
- VirtualBox + Ubuntu Server 26.04 (виртуальная машина)
- Основной ПК: Windows 10/11
- Пользователь: anastasiia

## День 2. Первое SSH-подключение

**Цель:** подключиться к Ubuntu Server с основного ПК по SSH.

**Что сделал(а):**
1. Перевёл(а) сеть VirtualBox из NAT в «Сетевой мост».
2. Узнал(а) адрес ВМ командой `ip a` — 192.168.1.xxx.
3. Подключился(ась): `ssh anastasiia@192.168.1.xxx`.
4. Проверил(а): `whoami`, `hostname`, `uname -a`.
Вывод: SSH работает, сеть в режиме моста, адрес ВМ 192.168.1.143.
